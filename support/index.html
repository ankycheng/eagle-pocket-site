Support

Frequently Asked Questions

How do I open my Eagle library?

Tap the library name in the top-left corner of the home screen, then tap Add Library. Use iOS Files to open a library from local storage, iCloud Drive, or a supported network/storage provider. These libraries may support editing and photo import when the provider allows writing.

How do I connect Google Drive?

When adding a library, select Google Drive as the source. Sign in and grant read-only Drive access. Browse folders under My Drive and choose your Eagle .library folder. The permission is a broad Drive read permission, not a Google-enforced grant limited to the selected folder; library content is downloaded from the folder you select.

The direct Google Drive integration does not upload, edit, move, or delete Drive files.

Can I edit or import photos into a Google Drive library?

Not through the direct Google Drive integration in the read-only release. Make changes with Eagle on your computer and allow the storage service to finish uploading them. After the first library sync, Eagle Pocket checks for updates about once per minute while the app is active and when you return to it, provided you are signed in. You can also start a sync manually. Changes appear after a successful sync; originals download when needed. Continuous background updates are not guaranteed by iOS. Editing and import remain available for supported libraries opened through iOS Files, subject to provider permissions.

Earlier Eagle Pocket versions could request Google Drive write access for import or editing. The read-only release will not reuse detected older write authorization and may ask you to remove it and reconnect.

My library isn't syncing. What should I do?

  1. Open Settings and check the Sync status.
  2. Read the error shown under Settings → Sync. For Google Drive, check the connected account under Settings → Google Account; use Sign in to Google Drive or Reconnect Google Drive when needed.
  3. Confirm that the account can open the actual library folder, and allow desktop uploads to finish. Ensure you have a stable internet connection.
  4. After access or connectivity problems are resolved, use Sync Now… → Sync New & Modified. Use Full Resync when you need to rebuild the local library from the source.
  5. If Google blocks authorization or reports that the app is not approved for the account, reconnecting or a full resync cannot override that restriction. Contact support with the error message and app version, without sending credentials or private library files.

A failed or interrupted Google Drive sync should be treated as incomplete; wait for a successful sync before expecting desktop changes to appear.

How do I clear the cache?

Settings → Storage → Clear Cache attempts to remove active downloaded files and designated image caches; cleanup failures may leave local files. This does not clear all database records, Google authorization, or separate recovery copies left by earlier versions. Cache clearing is blocked when recorded pending Google Drive changes exist, to protect local work. This read-only release cannot upload changes left pending by an earlier write-enabled version. For Google Drive, run a successful sync after clearing the cache to rebuild local metadata and file mappings before downloading originals again.

What happens when I sign out, revoke access, or delete a library?

Sign Out ends the connected app session but retains downloaded library data. To revoke the Google authorization itself, remove Eagle Pocket in your Google Account settings. Revocation prevents subsequent authorized Drive access but does not delete copies already downloaded.

Delete Library removes the library's app database record and associated imported records and attempts to remove its active local file cache; it does not delete the source folder or revoke Google authorization. Save any unsynced local work from an earlier version before deleting a library or the app: this read-only release cannot first upload pending changes to Drive. If an earlier version left separate recovery copies, this release does not expire or provide an in-app purge for them, and neither Clear Cache nor Delete Library removes them. Deleting the app removes its local container; exported files and operating-system/provider backups may remain. See the Privacy Policy for details.
